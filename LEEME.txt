CAMBIO DE PROVEEDOR DE TOKENS — 2026-10-09
El asistente, el informe ejecutivo, el glosario, los vinculos riesgo-requerimiento
y el borrador de EBITDA pasan a DeepSeek. El triage de documentos (PDFs) sigue como esta.

QUE HACER
1. Copia las carpetas de este zip SOBRE tu carpeta C:\jla (pisa 4 archivos).
2. Agrega la clave de DeepSeek como variable de entorno en Vercel:
   vercel.com → proyecto jla → Settings → Environment Variables → Add
   Nombre:  DEEPSEEK_API_KEY
   Valor:   (tu clave de platform.deepseek.com → API keys)
   Marcar Production, Preview y Development → Save
3. En C:\jla, en la terminal:
   git add -A
   git commit -m "feat: asistente e informes de texto con DeepSeek"
   git push

RED DE SEGURIDAD
Si la variable DEEPSEEK_API_KEY faltara o la borras, todo vuelve solo al proveedor
anterior sin romperse. Podes hacer el push antes o despues de cargar la clave.
